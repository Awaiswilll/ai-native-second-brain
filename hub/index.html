Using Potpie in any repo

Potpie indexes a codebase into a searchable graph for AI agents. Setup is one command per repo, then the graph follows resolve / search / record commands. Everything runs locally on G3.

# 1. Point Potpie at any repo (run from the repo root, or pass --repo)
potpie setup --repo /path/to/your/project --agent claude --yes

# 2. Check the daemon + your pot
potpie status            # daemon, pot, backend
potpie pot list          # your named pots (e.g. default)

# 3. Ask about the codebase — semantic, graph-backed answers
potpie resolve "where is the checkout flow implemented?"
potpie search "payment webhook error handling"
potpie record "the S3 bucket is migrated to the new provider" --authority user_statement

# 4. Build / inspect the graph
potpie graph status      # claims, entities, predicates
potpie graph ui          # visual graph browser

# 5. Bring the repo context into an agent
claude --prompt 'load context for this repo via potpie'   # requires the claude skills potpie installs

Supported agents: claude, codex, cursor, opencode. Skills are installed per agent automatically during setup. The second brain is already registered — switch sources any time with potpie setup --repo <path> --agent <agent>.
